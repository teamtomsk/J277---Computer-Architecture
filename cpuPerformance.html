02 / Clock speed

More ticks in the same time.

The clock helps coordinate CPU operations. Clock speed is the number of clock cycles per second, measured in hertz (Hz). 1 GHz = 1 billion cycles per second.

Slow-motion model: both CPUs have the same design and a job needing 12 clock cycles. One step shows 1 cycle on the left and 1, 2 or 3 on the right. Screen steps are not real seconds.

CPU A · 1 GHz

Remember: higher clock speed can help a comparable CPU do the same work sooner. A clock cycle is not always one complete instruction.

03 / Cores

Can we share the work?

A core is a processing unit within the CPU. More cores can process more tasks at the same time—if the work can be shared.

Each task needs two model steps. Cores have the same speed. This ideal model leaves out the time needed to organise shared work.

04 / Cache

Keep useful things close.

Cache is small, fast memory in or close to the CPU. It stores copies of instructions and data that may be needed again. A cache access is faster than getting the same item from main memory (RAM).

Small cache · 2 spaces

Larger cache · 4 spaces

Toy model: a hit (already in cache) costs 1 time unit; a miss (get it from RAM) costs 5, including filling the cache. Both caches start empty. When full, replace the item not used for the longest time. Real sizes and timings vary.

Remember: more useful items in cache → fewer slower RAM accesses → less waiting. Larger cache does not help every pattern equally.

Is cache the same as RAM or storage?

No. Registers hold tiny amounts of immediate working data inside the CPU. Cache is fast memory for reuse. RAM holds programs and data currently in use. Secondary storage keeps files long term.

Cache may have levels called L1, L2 and L3. You do not need fixed sizes or hit-rate percentages for this lesson. Focus on why reducing RAM accesses helps.

06 / Optional extra

A computer with a specific job.

An embedded system is a computer system built into a larger device for a specific purpose. A general-purpose computer can run a wide range of applications.

Embedded systems often prioritise reliability, cost and low power use. They can still be powerful and may receive software updates: their specific purpose is what makes them embedded.
